#Student Pass/Fail Prediction Model

#PROJECT OVERVIEW
This project uses Machine Learning to predict whether a student will pass or fail based on learning-related features.

## Features
- Data inspection and preprocessing
- Dummy Classifier baseline
- Logistic Regression
- Random Forest Classifier
- Model evaluation
- Saved model using Joblib
- Student prediction using Streamlit

#TECHNOLOGIES USED
- Python
- Pandas
- Scikit-learn
- Joblib
- Streamlit
- Jupyter Notebook

#HOW TO RUN
1. Install the required libraries.
2. Open the project notebook.
3. Run the notebook cells.
4. Open the terminal.
5. Run `streamlit run app.py`.

#RESPONSIBLE USE
This project uses synthetic student data for educational demonstration only. Predictions must not be used to judge or penalize real students.
